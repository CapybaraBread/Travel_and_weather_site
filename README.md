# 🌤️ Telegram Weather Bot

бот, показывающий погоду по городам России. Запрашивает погоду через API Яндекс.Погоды и отправляет ссылку на сайт с погодной информацией.

---

## Возможности

- Выбор из популярных городов через кнопки
- Отправка ссылки на внешний сайт с результатами

---

## Установка и запуск

```bash
# Клонируй проект
git clone https://github.com/your-username/weather-bot.git
cd weather-bot

# Создай и активируй виртуальное окружение
python3 -m venv venv
source venv/bin/activate

# Установи зависимости
pip install -r requirements.txt

# Создай .env файл с токенами
```

```
API_TOKEN=твой_тг_токен
YANDEX_WEATHER_TOKEN=твой_яндекс_токен
```

```bash
# Запусти бота
python bot.py
```
