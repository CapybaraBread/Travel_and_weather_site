# Travel & Weather Assistant

**Комплексное решение для путешественников:** сайт с интерактивной информацией о погоде и экскурсиях по городам России + Telegram-бот, через который всё начинается.

---

## Описание

**[Сайт](https://msk.durka.keenetic.pro/website/)** — это веб-платформа, где пользователи получают:

- 🔸 Актуальную погоду в выбранном городе (температура, осадки, ветер, влажность)
- 🔸 Подборку экскурсий с описанием, ценой и рейтингом
- 🔸 Эстетичный и удобный интерфейс с фокусом на путешественников

**Бот** в Telegram служит как точка входа:
- Предлагает выбор из популярных городов
- Делает запрос к API Яндекс.Погоды
- Сохраняет JSON с данными о погоде 
- Перенаправляет пользователя на сайт для просмотра полной информации

## Установка

```bash

git clone https://github.com/your-username/weather-travel-assistant.git
cd weather-travel-assistant

# Виртуальное окружение
python3 -m venv venv
source venv/bin/activate

# Установка зависимостей
pip install -r requirements.txt

# .env файл
```

```

YANDEX_WEATHER_TOKEN=твой_яндекс_токен
```

## Запуск

```bash
python bot.py
```

Бот предложит пользователю выбрать город, сохранит данные о погоде и отправит ссылку на сайт:

## Пример работы

1. Пользователь запускает бота и выбирает город
2. Бот сохраняет JSON с погодой и пересылает ссылку на сайт
3. Сайт парсит нужные данные, отображает:
   - Погоду сейчас и на 10 дней
   - Список экскурсий с ценами и рейтингами
   - Отзывы, формы обратной связи и подписки
